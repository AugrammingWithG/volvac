Why it is staged,
and why in this order.

  • Decisions come before production.

    Facts, structure and identity are settled first because every later stage is built on them. Changing a wordmark before the 3D is finished is a small job. Changing it afterwards is a large one.

  • Each price is a count, not a guess.

    One homepage journey, ten maker pages, six services, two contact lines. The scope can be counted, so each stage can be fixed. If a stage runs long, that is our cost and not yours.

  • The largest stage is already proven.

    3D production takes the most skilled hours and is what sets the site apart. The concept already models all six instrument groups and runs in a browser, so that stage finishes existing work instead of starting from nothing.

  • equal invoices.

    Each stage is one month and one invoice of , so the cost arrives evenly. Each stage ends on a sign-off, so you are never committed further than the stage you are in.
